# Total.js Developer image

`totalvm.png` is the image of the installer: Tux hugging the Total.js logo. It
is the artwork of the TotalVM app, resized to 640 px.

Tux, the Linux mascot, was created by Larry Ewing (lewing@isc.tamu.edu) with
The GIMP. The Total.js logo and this composition are marks of Spanish Total.js
and are not licensed for reuse (see `docs/legal.md`).
