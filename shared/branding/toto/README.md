# Toto

Toto, the European red fox (*Vulpes vulpes*), is the mascot of Spanish Total.js.
Official, unmodified artwork from https://github.com/totaljs-es/toto (2026-10-27).
Use the existing poses; do not redraw the character. Keep the Total.js logo for
system icons and the boot splash. Toto accompanies welcome and help text.

These files and Toto's appearance in generated wallpapers are subject to
[the proprietary Toto license](LICENSE.md), not MIT or CC BY-SA.
Attribution: Toto, mascot of [Spanish Total.js](https://totaljs.es/).
Identity and pose guide: https://totaljs-es.github.io/toto/.

`toto.jpg` was rendered from the generated SVG with Chromium for this revision;
the local Inkscape build could not decode PNGs. The regular wallpaper exporter
continues to use Inkscape on a working installation.
