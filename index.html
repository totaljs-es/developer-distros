Total.js Developer packages

The signed repository of Total.js Developer: a development environment for Total.js on Ubuntu 26.04 LTS. It is used by apt, and this page is its index.

Add it to Ubuntu 26.04

curl -fsSL https://totaljs-es.github.io/developer-distros/repo/totaljs-developer.gpg | sudo tee /usr/share/keyrings/totaljs-developer-archive-keyring.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/totaljs-developer-archive-keyring.gpg] https://totaljs-es.github.io/developer-distros/repo/ubuntu resolute main" | sudo tee /etc/apt/sources.list.d/totaljs-developer.list
sudo apt update
sudo apt install totaljs-developer-release totaljs-docker-source
sudo rm /etc/apt/sources.list.d/totaljs-developer.list
sudo apt update
sudo apt install totaljs-developer-server

For the desktop edition, install totaljs-mozilla-source with the other two sources, and totaljs-developer-desktop at the end. To install from nothing, with the Ubuntu installer, see the installation guide.
